# ArrayLab

Небольшая программа для работы с массивом чисел. Написал её на C# и Windows Forms в рамках курса по тестированию ПО. Здесь есть сам алгоритм, интерфейс для ввода данных и модульные тесты.

## Что делает

Находит минимум и максимум и обнуляет элементы между ними. Например:

```text
Вход:      5  1.2  -10  4.4  20  0
Результат: 5  1.2  -10  0    20  0
```

Числа можно ввести вручную, сгенерировать или загрузить из TXT/XLSX. Результат отображается в таблице; есть сохранение в файл и журнал действий. При повторяющихся экстремумах интерфейс предлагает выбрать диапазон. Если все числа равны, пользователь решает, обнулять ли внутренние элементы.

Сам `ArrayProcessor` работает без диалогов: выбирает максимальный интервал между минимумом и максимумом, возвращает копию массива, а при равных элементах оставляет значения прежними. Это поведение проверяют тесты.

## Запуск

Нужны Windows и .NET SDK 10. Для XLSX используется ClosedXML.

```powershell
dotnet restore ArrayLab.slnx
dotnet run --project src/ArrayLab/ArrayLab.csproj
```

Пример для загрузки лежит в [examples/input.txt](examples/input.txt). В первой строке TXT — количество элементов (от 1 до 20), во второй — числа через пробел. Для Excel количество задаётся в A1, а элементы — во второй строке первого листа.

## Тесты

```powershell
dotnet test tests/ArrayLab.Tests/ArrayLab.Tests.csproj
```

В наборе MSTest — семь методов: обычный и обратный порядок экстремумов, соседние минимум и максимум, короткий массив, повторяющиеся экстремумы, одинаковые числа, пустой массив и `null`. Все семь прошли проверку на Windows с .NET SDK 10.0.402. Они проверяют алгоритм; импорт файлов и диалоговые окна автоматическими тестами пока не покрыты.
